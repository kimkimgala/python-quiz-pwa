# Python Quiz PWA v1.7

Androidタブレット等で利用できる、オフライン対応の学習問題PWAです。

## v1.7 のポイント

v1.7では、v1.6の「教材作成アシスタント」にCSV一括読込を追加しました。Excel等で多数の問題を表形式で作成し、CSV UTF-8として保存して読み込むことで、教材JSONへ変換できます。

- `course-builder.html` で従来どおりフォーム入力が可能
- CSVひな型をブラウザから保存可能
- Excel等でひな型を編集し、CSV UTF-8（コンマ区切り）で保存
- CSVから複数問題を一括読込
- 読込後は問題ごとのフォームへ展開され、内容を目視確認・修正可能
- 引用符付きセル、セル内のカンマ・改行に対応
- 読込後もv1.6と同じ入力チェック・JSONプレビュー・JSON保存を利用
- 作成したJSONを `courses/` に追加すればGitHub Actionsが自動検証し、`catalog.json` へ登録

## CSV / Excelで教材を作る流れ

1. 学習アプリから「教材を作成」を開きます。
2. 「CSVひな型を保存」で `course-template.csv` を保存します。
3. Excel等でひな型を開き、問題を行単位で入力します。
4. Excelから「CSV UTF-8（コンマ区切り）」で保存します。
5. 教材作成アシスタントでCSVファイルを選択し、「CSVを読み込む」を押します。
6. 読み込まれた問題を画面で確認・必要に応じて修正します。
7. 教材ID、教材名、説明等の教材情報を入力します。
8. 「内容をチェック」「JSONをプレビュー」で確認します。
9. 「教材JSONを保存」で `<course_id>.json` を保存します。
10. 保存したJSONをGitHubの `courses/` フォルダへ追加します。
11. GitHub Actionsが検証し、正常なら `catalog.json` へ自動登録します。
12. 利用者の「教材を追加」に新教材が表示されます。

## CSVの列

基本列は次の10列です。

```text
章,問題番号,問題形式,問題文,選択肢A,選択肢B,選択肢C,選択肢D,正解,解説
```

必須列は `章`、`問題番号`、`問題文`、`選択肢A`、`選択肢B`、`正解`、`解説` です。`問題形式`、`選択肢C`、`選択肢D` は省略可能です。問題形式が空欄の場合は、入力された選択肢数から「正誤判定」「三者択一」「四者択一」を自動判定します。

## 教材作成アシスタントの主なチェック

- 教材IDが英数字で始まり、英数字・ハイフン・アンダースコアのみであること
- 教材名が入力されていること
- クリア回数が1以上の整数であること
- 問題が1問以上あること
- 章・区分が入力されていること
- 問題番号が整数で重複していないこと
- 問題文が入力されていること
- 選択肢が2個以上あること
- 正解が実際の選択肢に存在すること
- 解説が入力されていること

このブラウザ側チェックに加え、GitHubへ追加した後は `tools/build_catalog.py` が再度検証します。

## v1.5 教材カタログ自動登録

新しい教材JSONを `courses/` に追加するとGitHub Actionsが自動起動します。

- `tools/build_catalog.py` が全教材を検証
- 検証に成功すると `catalog.json` を自動生成・更新
- 新教材は利用者の「マイ教材」へ勝手に追加されず、「教材を追加」に候補として表示
- `catalog.json` は自動生成ファイルとし、原則として人が直接編集しない

## 既存Python教材について

既存のPython教材は互換性のため、当面 `questions.json` のまま自動生成対象に含めます。`course_id` は `python-basic-v1` のままなので、既存の学習履歴は維持されます。

既存の次の2教材だけはv1.3からv1.4への移行互換性のため、生成されたカタログで `default_subscribed: true` になります。

- `python-basic-v1`
- `cassette-demo-v1`

今後 `courses/` に追加する新教材は、自動登録されても各端末のマイ教材には自動追加されません。

## マイ教材

各端末の `localStorage` に、利用中の教材IDを保存します。

- 保存キー: `subscribed_courses_v1`

配信カタログに新教材が追加されると、各利用者がオンライン時に最新の `catalog.json` を取得します。新教材は「教材を追加」に表示され、本人が「マイ教材に追加」を押した教材だけが学習画面に表示されます。

## 主なファイル

- `index.html`: 共通の学習アプリ本体
- `course-builder.html`: v1.7 教材作成アシスタント（フォーム + CSV一括読込）
- `catalog.json`: 自動生成される配信教材カタログ
- `questions.json`: 既存Python基礎教材
- `courses/*.json`: 追加教材カセット
- `tools/build_catalog.py`: 教材検証・カタログ生成
- `.github/workflows/build-catalog.yml`: 教材追加時の自動処理

## 学習履歴

学習履歴は教材の `course_id` ごとに各端末のブラウザ `localStorage` に保存します。GitHubには送信しません。教材を切り替えても成績は混在しません。

## オフライン

Service Workerがアプリ本体、教材作成アシスタント、教材カタログ、取得済み教材をキャッシュします。JSONはオンライン時には最新版を取得し、取得できない場合はキャッシュを利用します。

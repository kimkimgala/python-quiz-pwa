# Python Quiz PWA v1.4

Androidタブレット等で利用できる、オフライン対応の学習問題PWAです。

## v1.4 のポイント

v1.4では、v1.3の教材管理を「マイ教材方式」へ発展させました。

- `catalog.json` は配信中の全教材を管理するカタログ
- 学習画面には、その端末で選んだ「マイ教材」だけを表示
- 新しくカタログへ登録された教材は自動でマイ教材へ追加しない
- 「教材を追加」から本人が選んだ教材だけをマイ教材へ追加
- マイ教材から外すときは「成績を残す」「成績も削除する」を選択可能
- 成績を残して外した教材は、後で再追加すると続きから学習可能
- 教材の追加・解除は端末単位で、他の利用者には影響しない

## マイ教材の保存

各端末の `localStorage` に、利用中の教材IDを保存します。

- 保存キー: `subscribed_courses_v1`

v1.3から初めてv1.4へ移行するときは、現在の標準教材のうちv1.3で削除されていない教材をマイ教材として初期登録します。既存の教材別学習履歴はそのまま利用します。

## 教材を追加する流れ

1. GitHubへ新しい教材JSONを追加します。
2. `catalog.json` の `courses` に `id`, `title`, `description`, `file` を登録します。
3. 各利用者がオンライン時にアプリを開くと、最新の配信カタログを取得します。
4. 新教材は「マイ教材」には勝手に入りません。「教材を追加」に候補として表示されます。
5. 利用者が「マイ教材に追加」を押すと教材JSONを取得・検証し、その端末のマイ教材へ登録します。

新教材を通常の選択教材として配信するときは `default_subscribed` を付けないか `false` にします。現在の既存2教材にはv1.3からの移行用として `default_subscribed: true` を設定しています。

## マイ教材から外す

「教材管理」から次のどちらかを選べます。

1. マイ教材から外す（成績は残す）
   - マイ教材一覧から外す
   - 学習成績は端末内に残す
   - 後で再追加すれば以前の成績から再開可能

2. マイ教材から外して成績も削除する
   - マイ教材一覧から外す
   - その教材の `learning_progress_<course_id>` も削除する

## カセット方式

- `index.html`: 共通の学習アプリ本体
- `catalog.json`: 配信教材カタログ
- `questions.json`: Python基礎教材
- `courses/cassette-demo.json`: カセット切替の動作確認用教材

教材JSON内の `course_id` は一意にし、`catalog.json` の `id` と一致させます。

## 学習履歴

学習履歴は教材の `course_id` ごとに各端末のブラウザ `localStorage` に保存します。GitHubには送信しません。教材を切り替えても成績は混在しません。

Python v1.0 の既存履歴は `python-basic-v1` へ一度だけ自動移行します。

## オフライン

Service Workerがアプリ本体、教材カタログ、取得済み教材をキャッシュします。JSONはオンライン時には最新版を取得し、取得できない場合はキャッシュを利用します。

「マイ教材に追加」を押す際にも教材JSONを取得するため、オンラインで追加に成功した教材はその時点でキャッシュ対象になります。

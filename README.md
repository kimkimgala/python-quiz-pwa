# Python Quiz PWA v1.6

Androidタブレット等で利用できる、オフライン対応の学習問題PWAです。

## v1.6 のポイント

v1.6では、v1.5の教材自動登録に加えて、ブラウザ上で教材JSONを作成できる「教材作成アシスタント」を追加しました。

- 学習画面の「教材を作成」から `course-builder.html` を開ける
- 教材ID、教材名、説明、サブタイトル、区分名、クリア回数をフォーム入力
- 問題を追加・削除できる
- 問題文、選択肢、正解、解説をフォームで入力
- 入力内容をv1.5互換ルールでチェック
- JSONプレビューを表示
- `<course_id>.json` として教材JSONを保存
- 作成画面の入力内容はブラウザ内だけで処理し、サーバーへ送信しない
- 作成したJSONを `courses/` に追加すれば、v1.5のGitHub Actionsが自動検証し、`catalog.json` へ登録

## 教材を作成する流れ

1. 学習アプリの「教材を作成」を開きます。
2. 教材ID、教材名、説明などを入力します。
3. 「＋ 問題を追加」で必要な問題数を作成します。
4. 問題文、選択肢、正解、解説を入力します。
5. 「内容をチェック」で入力不備を確認します。
6. 必要に応じて「JSONをプレビュー」で内容を確認します。
7. 「教材JSONを保存」で `<course_id>.json` を保存します。
8. 保存したJSONをGitHubリポジトリの `courses/` フォルダへ追加します。
9. GitHub Actionsが自動検証し、正常なら `catalog.json` へ自動登録します。
10. 利用者の「教材を追加」に新教材が表示されます。

## 教材作成アシスタントの主なチェック

- 教材IDが英数字で始まり、英数字・ハイフン・アンダースコアのみであること
- 教材名が入力されていること
- クリア回数が1以上の整数であること
- 問題が1問以上あること
- 章・区分が入力されていること
- 問題番号が整数で重複していないこと
- 問題文が入力されていること
- 選択肢が2個以上あること
- 選択肢キーが重複していないこと
- 正解が実際の選択肢キーに存在すること
- 解説が入力されていること

このブラウザ側チェックに加え、GitHubへ追加した後は `tools/build_catalog.py` が再度検証します。そのため、教材作成時と公開時の二段階でチェックされます。

## v1.5 教材カタログ自動登録

新しい教材JSONを `courses/` に追加するとGitHub Actionsが自動起動します。

- `tools/build_catalog.py` が全教材を検証
- 検証に成功すると `catalog.json` を自動生成・更新
- 新教材は利用者の「マイ教材」へ勝手に追加されず、「教材を追加」に候補として表示
- `catalog.json` は自動生成ファイルとし、原則として人が直接編集しない

通常の新教材は `courses/` にJSONファイルを1つ追加するだけです。

例:

```text
courses/project-finance-v1.json
```

教材JSONの基本形:

```json
{
  "course_id": "project-finance-v1",
  "title": "プロジェクトファイナンス基礎",
  "description": "プロジェクトファイナンスの基本事項を学習する教材",
  "subtitle": "基礎編",
  "section_label": "章",
  "clear_count": 3,
  "questions": []
}
```

実際の教材では `questions` に1問以上の有効な問題を入れてください。

## 既存Python教材について

既存のPython教材は互換性のため、当面 `questions.json` のまま自動生成対象に含めます。`course_id` は `python-basic-v1` のままなので、既存の学習履歴は維持されます。

既存の次の2教材だけはv1.3からv1.4への移行互換性のため、生成されたカタログで `default_subscribed: true` になります。

- `python-basic-v1`
- `cassette-demo-v1`

今後 `courses/` に追加する新教材は、自動登録されても各端末のマイ教材には自動追加されません。

## マイ教材

各端末の `localStorage` に、利用中の教材IDを保存します。

- 保存キー: `subscribed_courses_v1`

配信カタログに新教材が追加されると、各利用者がオンライン時に最新の `catalog.json` を取得します。新教材は「教材を追加」に表示され、本人が「マイ教材に追加」を押した教材だけが学習画面に表示されます。

マイ教材から外すときは、「成績を残す」「成績も削除する」を選択できます。

## 主なファイル

- `index.html`: 共通の学習アプリ本体
- `course-builder.html`: v1.6 教材作成アシスタント
- `catalog.json`: 自動生成される配信教材カタログ
- `questions.json`: 既存Python基礎教材
- `courses/*.json`: 追加教材カセット
- `tools/build_catalog.py`: 教材検証・カタログ生成
- `.github/workflows/build-catalog.yml`: 教材追加時の自動処理

## 学習履歴

学習履歴は教材の `course_id` ごとに各端末のブラウザ `localStorage` に保存します。GitHubには送信しません。教材を切り替えても成績は混在しません。

Python v1.0 の既存履歴は `python-basic-v1` へ一度だけ自動移行します。

## オフライン

Service Workerがアプリ本体、教材作成アシスタント、教材カタログ、取得済み教材をキャッシュします。JSONはオンライン時には最新版を取得し、取得できない場合はキャッシュを利用します。
